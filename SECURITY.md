# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include the app version, Android version and steps to reproduce. You'll get a reply within a week, and a fix will be
released as soon as practical, with credit to you unless you prefer otherwise.

## Scope

DayPurse has no network access and no server, so most issues will involve data on the device: other apps reading
or changing DayPurse data, the app lock being bypassed, or exported files exposing more than expected.
